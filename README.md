# Gantt CSS releases

Windows installers for Gantt CSS (Construction Scheduling Software), the construction planning, estimating and commercial control app by Gantt Planning.

This repository holds release installers only. The source code is not here.

## Installing

Download `Gantt-CSS-Setup-<version>.exe` from the latest release and run it. The installer is not code-signed yet, so Windows
SmartScreen may warn: choose **More info**, then **Run anyway**.

## Updates

Gantt CSS checks this repository for new releases. When one is out, a banner offers to download it, and the update installs
when you restart the app. You can also check from **Help ▸ Check for Updates…**.
